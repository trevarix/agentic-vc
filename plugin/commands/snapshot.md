description: Save an AVC snapshot of the current project state
argument-hint: [label]

Take an AVC snapshot now.

Call **avc_snapshot** with `$ARGUMENTS` as the label. If no label was given, write one yourself from the recent conversation — 2 to 5 words describing the state being saved.

Use the `auto:` prefix only for snapshots you took on your own initiative. A snapshot the user explicitly asked for is theirs, so use their label verbatim.

Report the snapshot ID and label back, and nothing else.
