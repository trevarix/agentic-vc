# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AVC, please **do not open a public GitHub issue**.

Instead, email **avc.dev247@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive an acknowledgement within 48 hours. We aim to release a fix within 90 days of the initial report. Once a fix is released, we will publish a security advisory on GitHub.

## Scope

This policy covers the `avc` CLI binary, the MCP server (`avc mcp serve`), and the VSCode extension.

## Supported Versions

Only the latest release receives security fixes. We recommend always running the latest version.
